# B2B Sales Lead Tracking & Pipeline Intelligence System

An Excel-based sales operations project designed to organize prospective customers, manage lead progression, monitor follow-ups, and analyze sales pipeline performance.

# Project Overview

This project demonstrates how spreadsheet automation and data visualization can support business development activities. It uses fictional B2B prospect records and a sample sales pipeline inspired by the digital verification industry.

The workbook is designed as a portfolio project relevant to Business Development Representative (BDR), Sales Operations, and Business Analytics roles.

# Key Features
Lead Management: Organizes prospect information, lead sources, interested services, estimated budgets, statuses, and follow-up dates.
Sales Pipeline Tracking: Tracks eight stages, from new leads to converted or lost opportunities.
Executive Dashboard: Summarizes total leads, active pipeline value, converted value, conversion rate, and overdue follow-ups.
Automated Alerts: Uses conditional formatting to highlight overdue follow-ups and distinguish converted and lost leads.
Data Validation: Provides dropdown menus for lead sources and pipeline statuses.
Sales Performance Analysis: Breaks down leads by pipeline stage and acquisition channel.
Visual Analytics: Includes a doughnut chart for lead distribution and a column chart for pipeline value.
BDR Workflow Guide: Documents daily lead management practices and the BANT qualification framework.

# Workbook Structure

# 1. Dashboard

Displays key sales KPIs, pipeline stage summaries, lead source performance, and charts.

# 2. Lead Tracker

Contains 20 fictional sample B2B prospect records, including lead sources, estimated deal budgets, lead statuses, follow-up dates, and remarks.

# 3. Instructions

Explains the workbook's workflow, dropdown options, conditional formatting, dashboard calculations, and BANT-based lead qualification.

# How to Use

1. Download `Sales_Lead_Tracking_System.xlsx` from this repository.
2. Open the workbook in Microsoft Excel.
3. Navigate to the **Lead Tracker** worksheet.
4. Add or update prospect records using the available dropdowns.
5. Maintain last-contact and next-follow-up dates.
6. Review the **Dashboard** for pipeline metrics and sales performance.
7. Refer to the **Instructions** worksheet for workflow guidance.

Microsoft Excel is recommended for recalculating formulas and displaying the dashboard as intended.

# Lead Qualification Framework

The workbook references the BANT framework:

Budget: Understand the prospect's budget.
Authority: Identify decision-makers and stakeholders.
Need: Determine the prospect's business requirements.
Timeline: Understand the expected purchasing timeline.

# Business Applications

This project illustrates how structured lead tracking can help business development teams organize prospect information, prioritize follow-ups, monitor opportunities, and make data-informed sales decisions.
